# AI動画編集 基礎編

YouTube用の動画を **AIツールを使って効率よく編集する全体の流れ** と、使うツールを解説します。

## 編集の全体フロー

1. 撮影データ（動画・音声）を用意する
2. **Vrew** で文字起こし＋無音カット
3. テロップ（字幕）を整える
4. BGM・効果音・画像・図を入れる
5. サムネイルを作る
6. 書き出して YouTube にアップロード

## 使うツール

- **Vrew**：文字起こし・無音カット・テロップを自動化
- **Claude Code / Codex**：台本・タイトル・概要欄の作成、作業の自動化
- **Canva 等**：サムネイル・図解の作成

> 基本の考え方：「作業」はAIに任せ、人は「判断（何を残すか・どう見せるか）」に集中する。
