## 使うツール

- **Vrew**：AIが音声を文字起こしし、無音カットやテロップ付けを自動化する動画編集ソフト
- **Claude Code / Codex**：台本・タイトル・概要欄の作成、繰り返し作業の自動化
- **Canva 等**：サムネイル・図解の作成
