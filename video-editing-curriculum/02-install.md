# Vrewのインストール方法

Vrewはパソコン（Windows / Mac）にインストールして使います。無料で始められます。

## インストール手順

1. ブラウザで「Vrew」と検索し、公式サイト（vrew.ai）を開く
2. トップページの「**無料ダウンロード**」ボタンをクリック
3. お使いのOS（Windows / Mac）に合ったインストーラーが自動でダウンロードされる
4. ダウンロードしたファイルを開き、画面の指示に従ってインストール
5. Vrewを起動し、メールアドレスで **アカウント登録（無料）**

> Macの場合：「開発元を確認できないため開けません」と出たら、システム設定 → プライバシーとセキュリティ →「このまま開く」で許可します。

## インストール後の初期設定

- 言語を「日本語」に設定
- マイク・音声の権限を許可
